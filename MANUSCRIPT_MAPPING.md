# Manuscript-to-software mapping

This guide maps the current manuscript to the supplied checks. Source paths are relative to the repository root. Output paths are relative to the **new destination selected with `--destination`**, such as `revision-rerun/`. The root [README.md](README.md) gives installation, execution and success checks.

Use the section names and source labels below to locate a result even if pagination changes. The original d=4 and d=6 examples are currently Main Eqs. **(49) and (50)**, labelled `eq:d4-example` and `eq:d6-example`. References to Eqs. (38)/(39) in preserved scripts, case descriptions and historical records identify these same inputs in the previous submission; they are not different examples.

The entry point verifies the supplied exact certificates and re-evaluates the numerical candidates; it does not require the exploratory searches that first found them. General proofs remain in the manuscript and SI. A finite numerical or certificate check must not be read as a proof of every state or every system size.

## Historical records

`validation_current/` is a preserved execution from **2026-09-30**, despite its directory name. It is useful for comparison, but it is not the receipt for a new execution. Use the output directory you selected when assessing your run. `validation_history/` and the module's `NUMERICAL_COMPARISON.md` retain older documentation, numbering and audit statements with their historical meaning. No separate author-side directory is required.
